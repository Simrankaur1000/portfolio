# Cybersecurity Portfolio

Personal portfolio showcasing cybersecurity projects, practical learning, and technical work across vulnerability assessment, penetration testing, networking, and digital forensics.

## Focus

- Vulnerability Assessment & Penetration Testing (VAPT)
- Web application security
- Network reconnaissance
- Digital forensics
- Capture-the-flag (CTF) learning

## Technology

The portfolio is built with Next.js, TypeScript, Tailwind CSS, and Motion-based UI components.

## Live site

[https://portfolio-k3wf.vercel.app](https://portfolio-k3wf.vercel.app)

## Run locally

```bash
git clone https://github.com/Simrankaur1000/portfolio.git
cd portfolio
npm install
npm run dev
```

Open http://localhost:3000.
